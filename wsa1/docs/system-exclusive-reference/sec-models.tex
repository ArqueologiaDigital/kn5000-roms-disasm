\chapter{SX-WSA1 and SX-WSA1R}\label{ch:models}

The SX-WSA1 keyboard and the SX-WSA1R rack module run the same program and speak the same
System Exclusive protocol. Two features are nonetheless available on the keyboard and not
on the rack, in both directions, and the two models put different bytes in the model
triple. Nothing else in the System Exclusive implementation depends on which model it is:
the framing, the checksum, the handshake, the error reporting, the parameter address space
and every other bulk-dump category are identical.

\begin{tabular}{lcc}

message framing, checksum, handshake & yes & yes \\

General MIDI On / Off & yes & yes \\

\midrule
\textsc{sequencer} bulk dump & yes & \textbf{no} \\

\bottomrule
\end{tabular}
\end{center}

\begin{caution}{On the rack, a SEQUENCER dump sends nothing and says nothing}
The rack's \textsc{sysex bulk dump} menu has no \textsc{sequencer} row: it is not drawn,
and the soft key that would select it does nothing. The category can still be reached over
MIDI, by a dump request addressed to \bytes{60 00 00}, and as part of \textsc{total
keyboard}. In both cases nothing is transmitted --- not even the end-of-category message
that closes every other transfer. A librarian waiting for data will simply time out.

On the rack the transfer-progress screen likewise lists only \textsc{sys,part\&midi},
\textsc{sound} and \textsc{combination}.
\end{caution}

The tempo message is refused in both directions on the rack: it will neither act on one
received nor send one.

\begin{note}{Telling the two apart over MIDI}
The middle byte of the model triple in anything the instrument transmits is \bytes{00} on
the keyboard and \bytes{01} on the rack; an identity enquiry (\bytes{F0 50 21 04 00 11 F7}
or \bytes{F0 50 22 04 00 11 F7}) is answered with the model's own value, whichever value
the enquiry itself carried. A second, behavioural test is to request a \textsc{sequencer}
dump and see whether anything arrives.
\end{note}

\begin{note}{Which machine is which}
The two behaviours are selected by a hardware input read once at power-on; the program
names neither model. The identification rests on two outside sources that agree.

The service documentation for that input identifies the machine that reads the second
value as the rack. Independently, Technics' own user guide marks the features the rack
lacks: its sequencer chapter is headed \textsc{sequencer (wsa1)}, and fifty-nine passages
across the guide carry the same \textsc{(wsa1)} marker for keyboard-only functions. A
model with no sequencer has nothing to put in a \textsc{sequencer} dump and no use for a
tempo message, which is exactly the pair of System Exclusive functions that machine
refuses.
\end{note}
