\chapter{Scope of this edition}\label{ch:limits}

This reference covers message framing, the bulk-dump transfer protocol, the universal
messages, and error reporting. The following are not covered.

\begin{description}
\item[Parameter meanings.] Chapter~\ref{ch:params} gives the structure of the parameter
  address space and the size of each block, but not what each individual parameter
  controls.
\item[Block contents.] Chapter~4 gives the address, length and repeat count of every
  message a dump contains, but not the meaning of the bytes \emph{inside} a block --- the
  structure of a sound, a combination or a sequence.
\item[Operating system version 1.] Everything here describes version 2.0.
\end{description}
