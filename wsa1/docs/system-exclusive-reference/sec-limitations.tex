\chapter{Scope of this edition}\label{ch:limits}

This reference covers message framing, the bulk-dump transfer protocol, the parameter
address space, the universal messages, error reporting and the differences between the two
models. The following are not covered.

\begin{description}
\item[What the parameters do.] Chapter~\ref{ch:params} enumerates all 108 addresses of
  the \bytes{00} area with their name, length, bit mask, accepted values and position in a
  dump. It does not explain what each setting does to the sound; the user manuals do that.
\item[Inside a combination part, and the SEQUENCER block.] Chapter~\ref{ch:blocks} takes both
  of those blocks down to the record level. What the 704
  bytes of a combination part hold beyond the name is in no published table --- the
  guide's own stop at the drum sound --- and would have to be decoded. How a stored
  sequence is arranged is likewise not covered.
\item[Operating system version 1.] Everything here describes version 2.0, whose
  \textsc{ver} byte is \bytes{11} --- exclusive specification 2.1. A machine speaking a
  different version announces it in that byte, which is the sixth of any message that
  carries one, so a receiver can tell at once that it is talking to something this
  reference does not describe.
\end{description}
