## Work in flight and its order

The rule that orders everything: the tree is edited by ONE writer at a time when an edit is
tree-wide (toolchain respell, event-code symbolization) or touches a single shared file
(wsa1 proms), and lanes otherwise own disjoint file sets. Read-only work runs in parallel with
anything.

1. **V1** (adversarial verify of Wave 3a T1; 3 lenses) -> T1 fix round if blockers/majors.
2. **Wave 2 claims review** (read-only, 10 reviewers x 2 lanes). Early results: midi 26/35
   confirmed, sys 17/30, accomp 21/26, audio 26/33; eight+eight recurring patterns (stale names
   after renames; "no reader" misses in-blob pointers and block copies; counts from the tool's
   range; v10 headers false in v7; v7 ports leaving numeric operands; callers credited to
   `_Helper` names; unreachable readers cited; ERP code withdrawn as data; text ports importing
   misframes; legacy names kept after retyping). Findings become per-file items for 3b lanes.
3. **wsa1 naming round 1** (read-only; 43 namer+skeptic pairs over 6,186 `sub_XXXXXX`) ->
   edit packs, applied serially with `scripts/tools/apply_label_edits.py` + `make gate-all`,
   then `wsa1/notes/prom_b_thunks_round6.py` re-derives the `T_` trampoline names from
   CONTENT targets.
4. **claims_lint.py** build + precision verification -> run tree-wide -> per-lane worklists.
5. **T2a** backend spellings/decodes (+ T1's remaining false-text items) -> V2a.
6. **T2b** tree-wide respell (`.byte` instructions, lda_dri / direct-address convergence, wsa1
   "cannot encode" tags, hi16/lo16) -> V2b. Solo: no lane edits during it.
7. **Event-code symbolization**: read-only research names the ~676 unnamed event values from
   their handlers (catalog: value -> name + evidence), then one solo pass defines the constants
   in the shared event_codes.s files and replaces the numeric operands tree-wide (2,299 v10/hdae
   occurrences already have a constant and only need the substitution). Event Code Freshness
   policy: technics-docs event-codes.md, hdae5000-homebrew.md, Mines/CLAUDE.md in step.
8. **Wave 3b lanes** on the post-T2b tree, roster = the Wave 2 roster (per-lane debt in
   `~/compartilhado/disasm-lanes/worklists-2026-10-02/`), each lane's worklist extended with its
   files' claims-review findings and claims_lint hits. Largest: NAKA (nakarest+nakabig: ~136 KB
   KNOWN-B, ~184 KB research), promb (85 KB / 69 KB), uimisc (92 KB KNOWN-B), tdata (87 KB),
   ext (41 KB); absurd-marker debt: accomp 1,360, proma 855, subcpu 432. wsa1 proma/promb lanes
   start only after the naming packs are integrated (same single file).
9. **wsa1 naming round 2** (routines whose callees were named in round 1), then re-measure,
   docs (technics-docs), blog post (owed since part 266), symbols/ regeneration.
