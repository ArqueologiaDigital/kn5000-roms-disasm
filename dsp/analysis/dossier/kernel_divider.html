Part II — The kernel

The fixed preamble that runs before every effect, on every frame

Part I covered the reverb algorithm itself. This part covers the kernel: 83 instruction words that execute on every frame regardless of which effects are selected — 60 in the header that runs before either effect body, and 23 in the output stage that runs after both.

It is included here for a specific reason rather than for completeness. Every saturation site in the emulated machine is in the kernel, and the kernel's coefficient cursor reads the parameter bank belonging to the second effect unit — which is the reverb's. The shared preamble therefore computes with the coefficients of whichever reverb preset the player has selected, and its arithmetic overflows by an amount that depends on that choice.
