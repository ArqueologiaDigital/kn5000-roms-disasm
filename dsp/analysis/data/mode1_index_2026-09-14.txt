   ★ TEST 1 -- THE ZERO CALIBRATION (part 231 sect. 3: zero exactly when unused)

      prod  mode-1 words                  n  addr8=0 addr8 != 0
      KN    WITH the store bit           11        0        11
      KN    WITHOUT the store bit        41        0        41

      ⇒ 327 of 327 mode-1 words carry a NON-ZERO `addr8', including every one of the
        228 that have no store and therefore no documented use for the field.
      ⛔ CONTROL, mode 2 (`addr8' IS a signed delta, 0 legal): 2455 of 5769 are ZERO (42.6 %).
        Zero is cheap where it means something.  Mode 1 never takes it.

   ★ TEST 2 -- THE CONSTANT CONTROL (a constant field is never zero either)
