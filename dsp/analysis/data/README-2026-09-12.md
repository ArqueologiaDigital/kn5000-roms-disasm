# Captures from the 2026-09-12 HLE-as-oracle / audio-gate session

Every number quoted in `N-INPUT-GATE-OPENED-2026-09-12.md`,
`N-EQ-TOPOLOGY-FROM-BYTECODE-2026-09-12.md`, `N-SINGLE-DELAY-RECURRENCE-2026-09-12.md` and the
two `N-DLYSEED2-*` notes is reproducible from the files here. All are `error.log` captures from
`kn7000_mame_build` with `-log`; gunzip before use.

## The rigs
* **Seeded trace** (delay/chorus/flanger): `dsp/tools/dlyseed_run.sh <TYPEIDX> <out.log>
  [--lo --hi] [--pshift N] [ENV=VAL ...]`. Note-on is at `36.0 s + 0.2 s x TYPEIDX`; the trace
  frame is that + 1 s. TYPEIDX 0 CHORUS, 3 FLANGER, 7 SINGLE DELAY, 15 PARAMETRIC EQ.
* **EQ frame pair** (the audio-gate work): two runs differing ONLY in `UPD6383_TRACE_FRAME`
  (1764000 / 1764001):
  ```
  DISPLAY=:0 DHLE=0 DSPCFG=3 TYPEIDX=15 NOTEMODE=0 TGM=0 UPD6383_PSHIFT=2 <ARMS> \
    UPD6383_TRACE_FRAME=<F> ./kn7000 kn5000 -rompath ./roms -skip_gameinfo -log -window \
    -autoboot_script dsp/tools/fx_ab.lua
  ```

## The tools that read them
| tool | question |
|---|---|
| `frame_pair_diff.py A B [--lo --hi]` | is the body actually running? (exit != 0 when static) |
| `dlyseed_confront.py T [--lo --hi --pshift --dump]` | multiplier/accumulator primitives, operand fate |
| `dlyseed_recurrence.py T [--pshift --fmtbit]` | the delay's per-frame recurrence at its fixed point |
| `eq_scale_solve.py T` | the EQ's per-coefficient scales from the ROM cells + flatness test |
| `chorus_wet_ab.py before.wav after.wav` | did an HLE wet-gain change land? |
