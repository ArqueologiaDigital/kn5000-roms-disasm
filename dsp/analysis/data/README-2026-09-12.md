⚠ **THREE** standing cautions now, all learned the hard way here:
1. never read cell RATIOS off a seeded or saturated frame;
2. diff a frame pair in EXECUTION order (`n`), not by `iw` — the frame runs `iw0..49`, then the
   body `iw84..188`, then `iw50..81`;
3. ★ **pooling captures pools MACHINES.** Every capture here was taken with a different set of
   default-off device arms, and a tool that pools them is comparing different emulators. Read the
   `UPD6383_*` report lines back out of the log (`class2_solve.py` does this automatically and
   prints the configuration count) before treating a disagreement as a contradiction.
⚠ And a fourth, about the criteria themselves: the chorus's **phase = 114** landmark is passed by
anything that empties the product register at the LFO entry word, **including configurations that
leave the EQ bit-identical across a frame pair**. It is a starvation signature as much as a
correctness signal — never quote it alone.
