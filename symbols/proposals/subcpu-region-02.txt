# region 2: 0x01F736..0x02219E
# System core: Serial-1 (MIDI) ring buffers, RESET/boot, the small preemptive RTOS the
# audio main loop runs as task 1 of, the inter-CPU micro-DMA link, a generic 3-instance
# byte-FIFO library, and the tone-generator/voice-slot primitives.
#
# Almost every address in this region already carries a real name in the authoritative
# LLVM build (llvm-nm -n on rebuilt_ROMs/kn5000_subprogram_v142.llvm.elf lists 346 symbols
# between 0x01F736 and 0x02219E, none of them LABEL_xxxxxx). What is NOT named is the code
# hiding inside fourteen ".byte" blobs that the LLVM source carries under placeholder cover
# labels ending in "_Opaque" (plus AudioBuf_PtrUtils). Those blobs are ~1.9 KB of real,
# reachable code. Everything proposed below is inside one of those blobs, so nothing here
# renames an analysed symbol. The 'replaces=' fields point at the placeholders that the
# HAND-CURATED symbols/subcpu_symbols_reference.txt still carries at the blob heads.
#
# Blob inventory (start..end taken from the next symbol in the ELF):
#   0x01FF7B..0x01FFD0  TaskList_Operations_Opaque      -> soft-timer service
#   0x02014D..0x020370  TaskQueue_Operations_Opaque     -> block/wake/event-flag primitives
#   0x0204C4..0x0204D1  TaskSem_AddrCalc_Opaque         -> semaphore peek
#   0x02080B..0x020849  RingBuf_Access_Opaque_A         -> task kill + tick delay
#   0x020851..0x0208B8  RingBuf_Control_Opaque          -> sched lock + 1K FIFO wrappers
#   0x0208C6..0x020966  RingBuf_ReadWrite_Opaque_A      -> 1K/256 FIFO wrappers
#   0x020974..0x020A14  RingBuf_ReadWrite_Opaque_B      -> 256/512 FIFO wrappers
#   0x020A22..0x020A65  AudioBuf_PtrUtils               -> 512 FIFO wrappers
#   0x020A7F..0x020AF4  RingBuf_WrappedRead_Opaque_A    -> 256-byte FIFO engine
#   0x020B0E..0x020B83  RingBuf_WrappedRead_Opaque_B    -> 512-byte FIFO engine
#   0x020B9D..0x020C12  RingBuf_WrappedRead_Opaque_C    -> 1K FIFO engine
#   0x020D13..0x020D2C  InterCPU_LatchProtocol_Opaque   -> the 0xE3 send
#   0x02197C..0x021A8E  VoiceState_OpaqueData1          -> part-handle / slot-list builders
#   0x021B3F..0x021BF5  VoiceState_OpaqueData2          -> active-voice collector
#
# Method: the ROM was re-disassembled with mame/unidasm resynchronised at every ELF symbol
# (offset = address - 0xEF00 for addresses >= 0x00F000; the first 256 ROM bytes are the
# 0x0400 vector-jump table), so every listing quoted below starts on a known-good boundary.

[DATA] 0x001034-0x00103F  Serial-1 / audio flag block (in-image RAM)
; 0x1034 = serial-1 flag byte (bit 0 = "send sync byte 0xFE next", bit 2 = "commands arrive
;          on the RX ring rather than the immediate F4/F5 handler"), 0x1036 = last SC1CR
;          value latched on a receive error by INTRX1_HANDLER, 0x1038 = baud-rate mode
;          (2 or 3, set by the F5/F4 commands), 0x103C = TaskSched task-descriptor array
;          base (entry for task N at 0x103C + 12*N; task 0 is a hole), 0x103E = audio
;          request flag word written by Timer_AudioTick_Handler and consumed by
;          Audio_Main_Loop (bit 1 = run the periodic re-init pass, bit 5 = cleared at the
;          top of every main-loop pass).

[DATA] 0x001040-0x001047  Audio tick counter and current task
; 0x1040 = free-running 32-bit tick counter, +1 per Timer_AudioTick_Handler entry, never
;          reset. Used by AudioLoop_CheckWatchdog (0x01FAF0), Audio_CheckQueuedData_Send
;          (0x01F836, flushes when 0x1040 - 0x102C >= 0x87) and TIMER_DELAY_TICKS (0x02083B).
; 0x1044 = cleared by TaskSched_ConfigAndDispatch; 0x1045 = interrupt-nesting counter
;          bumped by INT16_TaskSwitch_Handler; 0x1046 = word pointer to the running task's
;          descriptor (0 = none).

[DATA] 0x001048-0x0010D3  TaskSched control block
; 0x1048/0x1054/0x1060 = the three live task descriptors (tasks 1..3), 12 bytes each:
;   +0 next, +2 prev (16-bit intra-DRAM list links), +4 saved XSP (32-bit),
;   +8 priority (1..3), +9 state (0 = free, 3 = blocked, 4 = ready/running),
;   +0x0A pending-signal count, +0x0B task id.
; 0x106C/0x1070/0x1074 = ready-queue heads for priorities 1..3 (self-linked next/prev).
; 0x1074 + 4*id = event-flag wait-queue heads (ids 1..2 -> 0x1078, 0x107C).
; 0x107E + 4*id = semaphore wait-queue heads (ids 1..4 -> 0x1082/0x1086/0x108A/0x108E).
; 0x1080-0x1081 = event latched-signal flag bytes (bit 0), both seeded to 1.
; 0x1091 + id   = semaphore counts (ids 1..4 -> 0x1092..0x1095), all seeded to 1.
; 0x1096/0x109A and 0x109E/0x10A2 = the two message-queue head pairs used by TaskMsgQ_Send
;   (0x0204D1) / TaskMsgQ_Receive (0x020642).
; 0x10A6 = pool of four 8-byte message nodes, free-list head at 0x10C6.
; 0x10CA = the single soft-timer slot (see TASKSCHED_SOFTTIMER_SERVICE).
; 0x10D2 = scheduler lock depth (word). Non-zero blocks all context switching.

[DATA] 0x0010E4-0x0010EF  Inter-CPU link state
; 0x10E4 = micro-DMA channel-0 destination pointer staged by INT0_HANDLER.
; 0x10E8 = DMA_XFER_STATE. Written 1 or 2 by the senders, decremented 2->1->0 by
;          MICRODMA_CH2_HANDLER (0x020F01). Every sub->main transmit path spins on it.
; 0x10EA = CMD_PROCESSING_STATE: 1 = ordinary command in flight, 2 = 0xE1 sequence,
;          3 = 0xE2 sequence, 4 = 0xE1 second phase. Decoded by MICRODMA_CH0_HANDLER.
; 0x10EC = the command byte last read from the main CPU latch at 0x120000.
; 0x10EE = set to 0xFF when a 0xE2 sequence completes.

[DATA] 0x001110-0x001127  Inter-CPU transfer descriptors
; 0x1110 (+0 source, +4 count) and 0x10DE = the two-phase 0xE1 transfer descriptors;
; 0x1116 = the 6-byte block INT0 receives for an incoming 0xE1; 0x111C = the 10-byte block
; received for an incoming 0xE2, replayed by Cmd_Check_E2_Pending (0x020FBC) into
; InterCPU_E1_DMA_Transfer; 0x1126 bit 7 = "an 0xE2 arrived, replay it from the main loop".
; 0x10D4 = the 10-byte parameter block staged by INTERCPU_E2_DMA_TRANSFER.

[DATA] 0x00F012-0x00F01D  Main-loop and DMA-watchdog counters (in-image RAM)
; 0xF012 = periodic-pass counter, wraps at 10 (Audio_Main_Loop).
; 0xF014 = audio-tick sub-phase 0..5, indexes the 6-entry jump table at 0x00F460 with base
;          0x01FB76; 0xF016 = counts phase-6 passes, sets bit 5 of 0x103E every 8.
; 0xF018 = count of forced inter-CPU RX resets performed by Cmd_DMA_Check_Stuck.
; 0xF01A = consecutive "no progress" polls of the receive micro-DMA counter.
; 0xF01C = last value read from micro-DMA channel-0's count register (cr 0x40).

[DATA] 0x01FD8C-0x01FDC1  Task creation table (4 entries x 12 bytes) + init seeds
; Entry for task N at 0x01FD8C + 12*N: +0 = 32-bit entry point, +4 = 32-bit initial stack
; top, +8 = 16-bit initial SR (0x8800 for all), +0x0A = priority, +0x0B = pad.
;   task 0: unused/garbage (never spawned).
;   task 1: entry 0x01FAB1 (the continuation of PostReset_InitAudio, i.e. Audio_System_Init
;           and Audio_Main_Loop), stack 0x0004069A, priority 3.
;   task 2: entry 0x01FC6F (a bare RET), stack 0x00040C20, priority 1 -- an empty slot.
;   task 3: entry 0x00036327 (-> jp 0x00038E0F), stack 0x00040A9C, priority 3.
; 0x01FDBC-0x01FDBD = the two 0x01 bytes copied to the event flags at 0x1080.
; 0x01FDBE-0x01FDC1 = the four 0x01 bytes copied to the semaphore counts at 0x1092.
; TaskSched_SpawnTask builds a 34-byte context frame at (stack top - 0x22): seven long
; register slots, then the SR word at +0x1C and the 4-byte entry address at +0x1E, which is
; exactly what TaskSched_ContextRestore (0x01FF72) pops.

[ROUTINE] 0x01FF7B TASKSCHED_SOFTTIMER_SERVICE  replaces=LABEL_01FF7B  confidence=high
; Software one-shot/periodic timer service. Walks the 1-entry timer table at 0x10CA
; (8 bytes/entry: +0 = down-counter word, +2 = reload word, +4 = 32-bit callback address,
; 0xFFFFFFFF = slot empty). For each armed slot it decrements +0; when the counter reaches
; zero it reloads it from +2, pushes the loop-advance address 0x01FFA8 as a return address
; and jumps to the callback, so the callback returns straight back into the walk.
; Runs the whole walk inside a scheduler lock: 0x10D2 (the lock-depth word) is incremented
; and mirrored into control register 0x7C on entry and decremented/mirrored on exit, with
; the interrupt mask raised to level 0 (all masked) for the walk and back to 6 afterwards.
; While the lock is non-zero TaskSched_Dispatch refuses to context-switch (see 0x01FF21).
; No caller was found by a whole-ROM branch-target scan; it is most likely reached through
; a dynamically installed vector (see Task_ConfigTimer 0x02072A). Register use: WA, XIX, B.

[LABEL] 0x01FF91 TASKSCHED_SOFTTIMER_ENTRY  confidence=high
; Top of the per-slot walk; XIX = current 8-byte timer entry, B = slots remaining.

[LABEL] 0x01FFA8 TASKSCHED_SOFTTIMER_NEXT  confidence=high
; Advance XIX by 8 and djnz; also the synthetic return address pushed for a fired callback.

[LABEL] 0x01FFAF TASKSCHED_SOFTTIMER_UNLOCK  confidence=high
; Restore interrupt level 6, decrement lock depth 0x10D2, mirror to cr 0x7C, return.

[LABEL] 0x01FFBF TASKSCHED_SOFTTIMER_FIRE  confidence=high
; Reload counter from +2, push 0x01FFA8, jp (XIX+4) -- i.e. tail-call the callback.

[ROUTINE] 0x02014D TASKSCHED_BLOCK_SELF  replaces=LABEL_02014D  confidence=high
; "Wait on my own pending count" - the counting half of a binary rendezvous.
; Reads the current-task descriptor pointer from 0x1046. If the descriptor's pending count
; (+0x0A) is non-zero it just decrements it and returns through TaskSched_ContextRestore
; (0x01FF72). Otherwise it unlinks the descriptor from its ready queue (next at +0, prev at

; picks another task. Entered with a full context already pushed (push SR + 7 long pushes),

; Inputs: none. Clobbers: everything (it either reschedules or restores the pushed context).

[LABEL] 0x02017D TASKSCHED_BLOCK_SELF_CONSUME  confidence=high

[ROUTINE] 0x0219DC VOICE_BUILD_PARTSLOT_LIST  confidence=medium
; Builds a 0xFFFF-terminated word list at 0x00286B describing the up-to-four sounding
; sub-slots of one tone entry.
; Inputs: A = tone/part row index, C = a group id, E = a group mask (the routine keeps
;         ~E in its frame and matches (table_byte & ~E) against (C & ~E)).
; Walks i = 0..3 over the bytes at (0x0024E6 + 12*A + 8 + i). A byte >= 0xC0 means "slot
; unused" and is skipped. Otherwise the byte indexes a 5-byte-stride table at 0x002129,
; whose first byte indexes VOICE_COMMANDINDEXTABLE (0x00F4EC); that result is the value

; whatever SlotPair_Decode_C_To_L (0x0210A2) returns for (WA = the raw byte, BC = i).
; Output: XHL = 0x00286B (the list). No caller found by branch-target scan.

[UNCERTAIN] Existing names 0x020849 "IntMask_SetBit3" / 0x02084D "IntMask_ClearBit3" look

; is the one the inter-CPU sender starts and MICRODMA_CH2_HANDLER stops (timer 2 paces the
; micro-DMA burst). TaskSched_ConfigAndDispatch brackets its interrupt-level programming
; with these two calls, which is consistent with "stop/restart the scheduler tick timer".

[UNCERTAIN] Existing name 0x01FAF0 "AudioLoop_CheckWatchdog" looks wrong. It compares the

; PE bit 0 (SFR 0x38) -- the bit MUTE_AND_HALT (0x01FBF4) clears. Nothing resets 0x1040, so
; this is a one-shot "un-mute about 1000 ticks after boot", not a watchdog.

[UNCERTAIN] Micro-DMA control-register numbering, inferred from use and not from a
